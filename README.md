# How to set up Wallpaperer

## Download Rainmeter
 - https://www.rainmeter.net/
 - Select the "Portable" Version and place it in your OneDrive/Apps folder (Create on if one is not there) (or anywhere else)
 - Open Rainmeter (can appear as rainmeter.exe)

## Extract Zip file and set up
 - Extract folder and copy the folder into your "Skins" folder in OneDrive/Apps
 - Expand the "Wallpaperer" folder in Rainmeter
 - Expand the "picker" folder in Rainmeter
 - Right click "wallpaper.ini" and press load
 - Uncheck "Draggable", check "Click Through", and change position to "On Desktop" and load order to -1

## Run Wallpaperer
 - Right click "Picker.ini" under the "picker" folder and press load
 - A window will appear, press "Open folder (Add Images)"
 - Drag your images into the folder (must be PNG, JPG/JPEG or GIF)
 - Close explorer and res refresh on the window
 - Then click the background you wish to enable

 ### Extra:
 - Wallpaperer is packaged with 2 background by default
